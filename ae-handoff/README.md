# Emote · AE 交接包

目标：佳明 Venu 4 45 mm，454 × 454 像素圆屏；画面只有黑色圆底、两根指针和两只眼睛，没有文字或嘴巴。

## 当前预览：参数化短弧版

`/orbit-preview.html` 已切换为 `clock-transition.js` 驱动的参数化版本。两根指针按起始左右就近落位，不再固定时针对应右眼；如 10:10 这类原本需要交换左右的位置，先在 0.20 秒内提前收短、弯曲转平，再在原侧落位。中心沿自动生成的三次贝塞尔路径移动，没有中间姿态关键帧。0–0.75 秒归位，0.75–1.00 秒睁眼。增加两次 18 Hz 的短衰减弹性脉冲，默认渲染轮廓变化小于一个设计像素，0.60 秒前消退。参数为路径弧度、转向延后、收缩延后、双针错拍、节奏偏前和微弹性，可在预览中调节。

`ClockTransition.forTime(分钟数, 参数)` 创建两个运动节点，`ClockTransition.at(节点, 秒数)` 返回位置、角度、宽高、圆角及弯曲量。弯曲时使用圆头贝塞尔描边，弯曲量为零时与圆角矩形轮廓一致。起始几何和路径控制点在创建节点时计算，渲染只读取时刻状态。`verify-clock-transition.cjs` 检查全天起始时间、参数边界、10:10 转向后的轮廓间隙及微弹性幅度。

以下 `.aep`、`.jsx` 与 `orbit-motion.js` 保留上一轮绕转版；当前参数化候选尚未同步到 AE 工程或 Garmin 真机包。

## 1 秒快速绕转版（本轮验收）

直接打开 `Emote_ClockEyes_Orbit_1s.aep`，查看合成 `Emote_06-30_ORBIT_1S`。这是 454 × 454、30 fps 的原生可编辑 Shape Layer 工程；运动在前 **1.00 秒**完成，合成后留 0.25 秒定格。旧工程 `Emote_ClockEyes_454.aep` 保留作对照。

编舞顺序：0–0.20 秒短暂收拢；0.20–0.50 秒两针分向外展；0.50–0.76 秒沿弧线绕转并错身；0.76–0.83 秒落成两条闭眼横线；0.83–1.00 秒睁开成圆角眼睛。时针最终落在右眼，分针落在左眼。其间使用连续的三次曲线补足低帧率参考视频里的空白，而不是逐帧描摹。

浏览器预览：运行项目根目录的 `node preview-server.cjs`，打开 `/orbit-preview.html`。可重播、暂停、拖动 1 秒时间轴，或开启红蓝识别标记检查两针路径；时间输入可检查任意起始时刻。

若要重建合成，运行 `Emote_ClockEyes_Orbit_1s.jsx`；它会读取上一级目录的 `orbit-motion.js`，因此需保持这两个文件的相对位置。生成后的 `.aep` 可独立打开。此版本仅用于动画验收，尚未写入 Connect IQ 真机包。

## 在 After Effects 中打开

1. 启动 AE，选择 `文件 → 脚本 → 运行脚本文件`，打开 `Emote_ClockEyes_454.jsx`。
2. 输入想要的起始时间，默认 `06:30`。脚本会生成两个 **454 × 454 / 30 fps / 3 秒** 合成：`CURRENT` 是现有直线基线，`AE_EDIT` 是当前实验台的可编辑候选。
3. 在时间线展开 `HOUR`、`MINUTE` 的 `Contents → Morphing hand → Path`，可编辑逐帧矢量路径；`Stroke Width` 可调整短暂挤压。`LEFT EYE`、`RIGHT EYE` 是独立圆角矩形矢量层，可编辑大小、圆角和角度。
4. 黑色 `SCREEN` 是真实圆屏。`GUIDE` 是 20 px 内缩参考圈，仅用于编辑，不参与最终渲染。完成后 `文件 → 另存为`，保存 `.aep`。

脚本不修改真机包；它向当前 AE 项目添加新合成。已在 After Effects 2024 中验证生成 `CURRENT` 与 `AE_EDIT` 两个合成，并保存为 `Emote_ClockEyes_454.aep`。

## 这份候选的参数快照

从当前右侧实验台读取：`06:30`；运动弧度 `13 px`；柔性弯曲 `17 px`；预备回拉 `6 px`；双针错拍 `35 ms`；转向延迟 `12%`；缩短延迟 `20%`；轻微挤压 `2 px`；转变用时 `0.70 s`；节奏为“轻快出发”。

时间结构：指针停留 `1.40 s` → 指针变闭眼 `0.55 s`（基线）或 `0.70 s`（候选）→ 睁眼 `0.30 s`。指针的弯曲只在运动中出现，起点和终点恢复为直线。

## 独立矢量参考

`clock-start-0630.svg` 与 `eyes-final.svg` 均为 454 × 454 SVG：前者是起始指针，后者是终点双眼。较新的 AE 支持将 SVG 导入为矢量素材或合成；如果版本不支持，运行 `.jsx` 即可直接得到原生 Shape Layer。SVG 是静态参考，完整动效在脚本生成的合成里。

后续若要把修改导回表盘，请保留 `.aep`，并导出一段 454 × 454 的 MP4 供视觉对照；最好记录你调整过的关键帧时间和曲线。任意时间的指针起点仍需由 Monkey C 实时计算，不能只靠一段固定影片覆盖。
