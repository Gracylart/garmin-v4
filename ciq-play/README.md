# Venu 4 双眼互动应用

**Emote Play** 是独立手表应用，不是表盘。当前版本 0.3.1。可在 Venu 4「设置 > 系统 > 快捷方式」中尝试把 Emote Play 指派给长按按键；具体是否可选及熄屏按键行为需真机确认。两者共用球面投影与 64 点圆角双眼绘制器。

- 单击：视线看向点击位置，并暂时在对应方向张望；同时切换随机表情。
- 短时间三连击：触发气鼓鼓、瞪眼与画面轻微震动。
- 连续慢速拖动：视线跟随手指。一笔绕屏幕画圈：庆祝并震动。只有从圆屏一侧外缘跨过中心、直达对侧外缘的长直滑动，会在达到条件的瞬间从当前眼神开始沿球面转满一圈，无需松手；眼睛在球背面被遮挡，再从另一侧出现，并在最后一段旋转中渐进回正。短滑与只有方向、没有轨迹的系统 Swipe 事件不会触发转圈，以免和其他手势冲突。
- 在小范围内反复来回拖动：触发躲避式“挠痒痒”反应。
- 步数事件发生在 1000–1999 步区间、完成运动：后台记录待庆祝事件；下次打开互动应用时庆祝并震动。当前尚未实现每日仅触发一次的持久化去重。前台检测到移动条从 0 变为非 0（久坐提醒的近似值）时生气，不会伪称直接收到了系统提醒。互动应用仍在前台时，屏幕从低功耗恢复有 50% 概率庆祝；无法区分抬腕、点屏或按键唤醒。
- 庆祝、生气和转圈会完整播放；播放期间点击、拖动及划动不会切换表情。

互动应用首次启动后才会注册步数与运动完成后台事件。应用开启时使用 50 ms 定时器；退出应用后不在后台持续绘制，不能从后台自动播放动画或震动。已取消 Connect IQ 传输完成触发。真机还需验收按键快捷启动、久坐移动条、屏幕唤醒回调及连续拖动轨迹。

画面保持纯黑底、仅双眼；已移除流彩、烟花和粒子。浏览器稿是交互验收工具，不代表真机帧率。
