# 浏览器与手表的交付边界

- `ciq/` 是 Emote Life 表盘；`ciq-play/` 是 Emote Play 前台互动应用。两者独立编译，沿用现有签名与 SDK 构建流程。
- `ciq/source/EyeShape.mc` 是既有共用眼睛绘制器。当前浏览器的视觉中心和活动圆修正尚未自动移植为 Monkey C 改动。
- 当前 18 项运动、SVG 逐帧、线条脱轨、拼装和融球均是网页实现。网页配置导出不会写入设备；仓库也没有把所有 JSON 帧直接装入表盘。
- 表盘沿用亮屏动画计时与低功耗停止绘制的策略；前台应用提供触摸互动。运动完成等系统事件的既有处理以各目录的 Monkey C 源码为准。
- 后续硬件开发需明确触发来源，选择运动资源格式与按需加载方案，再以模拟器和 Venu 4 45 mm 实测内存、帧率、耗电、后台切换和恢复。网页测试不能替代这些验收。
- 本次 GitHub 整理只运行浏览器与资源验证；没有重新构建 `.prg`，没有更换手表当前应用。

Mac：设置 `CIQ_SDK_ROOT`、`CIQ_DEVELOPER_KEY` 后执行 `npm run build:mac`。Windows：执行 `build.ps1` 并按需设置 `-SdkRoot`、`-Device`。签名密钥和构建产物保持在 Git 之外。
